プライバシーポリシー

有効日：2026年11月20日　運営者：KIGEN

このポリシーは、KIGEN の運営者専用のツール「KIGEN ENGLISH OAuth」（以下「本ツール」）が、Google のアカウントの情報をどのように扱うかを説明します。本ツールの利用者は、KIGEN の運営者本人だけです。

This policy explains how "KIGEN ENGLISH OAuth" (the tool), used only by the KIGEN operator, handles Google account data.

1. YouTube API サービスの利用

本ツールは YouTube API サービスを使用しています。本ツールの利用には、Google プライバシー ポリシー（http://www.google.com/policies/privacy）が適用されます。

The tool uses YouTube API Services. See the Google Privacy Policy at http://www.google.com/policies/privacy.

2. アクセスする情報と使い道

本ツールは、運営者が Google の同意画面で許可した次の範囲だけでアクセスします。

  • YouTube の動画の管理（youtube.upload）：運営者の動画を、運営者のチャンネルへ非公開でアップロードし、公開の日時を予約し、サムネイルを設定するため。
  • YouTube アカウントの表示（youtube.readonly）：投稿先のチャンネルの ID と、アップロードした動画の状態（非公開であること・公開予定の日時・チャンネル・タイトル）を読み取って確かめるため。

本ツールは、視聴者の情報、コメントの本文、コメントした人の情報を収集・保存しません。

3. 保存するもの・保存する場所

  • 認証の情報（OAuth のトークン）：Windows のデータ保護機能（DPAPI）で、運営者の Windows アカウントに結びつけて暗号化し、運営者のパソコンの中の、運営者の Windows アカウントだけが読めるように権限を設定したフォルダーに保存します。インターネット上のサーバーには保存しません。
  • 作業の記録：アップロードした動画の ID、動画ファイルのハッシュ値（同じ動画を二度アップロードしないため）、日時、公開の設定、投稿先のチャンネルの ID を、運営者のパソコンに記録します。
  • YouTube から受け取った情報の更新：動画の ID や公開の状態など、YouTube API サービスから受け取った情報は、毎日の確認で、受け取ってから 30 日を過ぎる前に YouTube から読み直して更新しています。

4. 共有

本ツールが YouTube API サービスから受け取った情報を、販売したり、広告に使ったり、広告事業者やデータ事業者などの第三者に提供したりしません。

運営者は、作業の補助として、AI のコーディング支援ツール（Anthropic の Claude Code）を運営者のパソコンで使っています。このとき、本ツールの実行結果（動画の ID・公開の状態・チャンネルの ID など）が、その AI ツールで処理されることがあります。認証の情報（トークン）は、表示も送信もしないように扱っています。

5. クッキーと端末の情報

本ツールはクッキーを使いません。このサイトは、アクセス解析や広告のツールを使っていません。このサイトは GitHub Pages で公開しており、GitHub がアクセスの記録を扱うことがあります（GitHub のプライバシーに関する声明をご覧ください）。

6. アクセスの取り消しと削除

  • 本ツールへのアクセスの許可は、Google のセキュリティ設定のページ（https://security.google.com/settings/security/permissions）から、いつでも取り消せます。
  • 運営者は、パソコンに保存したトークンと作業の記録を、いつでも削除できます。
