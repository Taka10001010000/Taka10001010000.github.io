KIGEN

KIGEN は、YouTube チャンネル「KIGEN SCIENCE」（研究を紹介する科学解説）と「KIGEN ENGLISH」（英語学習）を運営する制作プロジェクトです。

KIGEN is a production project that runs the YouTube channels KIGEN SCIENCE (science explainers) and KIGEN ENGLISH (English learning).

KIGEN ENGLISH OAuth（運営者専用の YouTube 連携ツール）

KIGEN ENGLISH OAuth は、KIGEN の運営者が自分の YouTube チャンネル「KIGEN ENGLISH」を管理するために、運営者のパソコンで使うツールです。YouTube API サービスを使い、次のことだけを行います。

  • 完成した動画を、運営者のチャンネルに非公開でアップロードし、運営者が承認した日時に公開されるよう予約する
  • 運営者が選んだサムネイルを、その動画に設定する
  • アップロードの後、動画の状態（非公開であること・公開予定の日時・投稿先のチャンネル）を読み取って確かめる
  • 投稿先のチャンネルが正しいかを、チャンネルの ID で確かめる

このツールを使うのは KIGEN の運営者だけです。ほかの人には提供していません。ログインやアカウント作成の機能はありません。

KIGEN ENGLISH OAuth is a tool used only by the KIGEN operator, on the operator's own computer, to manage the operator's YouTube channel KIGEN ENGLISH through YouTube API Services: it uploads finished videos privately, schedules their publication at a time the operator approved, sets the operator's chosen thumbnail, and reads back the video status and channel ID. It is not offered to anyone else.
